# Creo模型树自动取号器 - 项目完成总结

## 项目概述

Creo模型树自动取号器包含两个版本：
- **桌面版**（PyQt6）：树形层级界面，数据存本地 JSON；
- **Web 版**（`creo编号器-web/`）：FastAPI + SQLite + React，数据存服务器，支持多电脑共享。

两版共用 `creo编号器/core` 核心编号逻辑，编号规则（v2）完全一致。

## 已完成的功能

### 1. 核心算法模块

**图号解析器 (parser.py)**
- 解析图号结构（前缀、层级码）
- 判断组件/零件类型
- 验证父级图号有效性
- 提取子组件和子零件列表

**图号生成器 (generator.py)**
- 生成下一个组件号（追加法：父级 + 两位数字）
- 生成下一个零件号（分叉法：父级 + `-` + 顺序数字）
- 溢出检查（组件最多99个）
- 统一生成入口

### 2. 图形用户界面

**主窗口 (main_window.py)**
- 输入父级图号
- 选择新建类型（组件/零件）
- 显示已有子图号列表
- 生成并显示新图号
- 历史记录管理
- 数据持久化（JSON文件）

### 3. 测试验证

- 核心功能测试通过
- 边界情况处理正确
- GUI程序可正常启动

## 使用方法

1. 安装依赖：`pip install -r requirements.txt`
2. 运行程序：双击 `run.bat` 或执行 `python start.py`
3. 输入父级图号，选择类型，点击生成

## 编码规则实现

（v2，详见 `Creo 模型树图号层级与编号规则（开发说明）.md`）

### 组件（追加法）
- 格式：父级图号 + 两位数字（01~99）
- 示例：`03S01201-100101` → `03S01201-10010101`

### 零件（分叉法）
- 格式：父级图号 + `-` + 顺序数字（1, 2, 3...）
- 示例：`03S01201-100101` → `03S01201-100101-1`

### 字母组件与主机层（v2）
- 字母组件（如 `-ZBC`）：下建组件用「根前缀 + 两位数字」全局编号（从 01 起）；下建零件用宿主（父级）共享序列（如 `-00-1`）
- 主机层（根的直接子级两位数字，如 `-00`）：只放字母组件（手动输入），不创建零件
- 数字组件（如 `-10`）：下建组件追加法（`-1001`）、下建零件分叉法（`-10-1`）
