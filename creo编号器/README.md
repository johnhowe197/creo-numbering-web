# Creo模型树自动取号器

用于Creo模型树图号自动编号的桌面应用程序。

> **注意**：本文件为 v1 说明。当前版本已升级为 v2（树形界面，见 `README_V2.md`），
> 并新增 Web 版（`creo编号器-web/`）。编号规则 v2 详见
> `Creo 模型树图号层级与编号规则（开发说明）.md`。

## 功能特性

- **图号解析**：自动解析图号结构，识别组件和零件
- **自动编号**：
  - 组件：追加法（父级图号 + 两位数字）
  - 零件：分叉法（父级图号 + `-` + 顺序数字）
- **历史记录**：保存编号历史，方便查询
- **数据持久化**：自动保存到本地JSON文件

## 使用说明

### 基本操作

1. **输入父级图号**：在输入框中输入父级图号（如 `03S01201-100101`）
2. **点击"解析"**：程序会显示该父级下的所有子图号
3. **选择类型**：选择要新建的是"组件"还是"零件"
4. **点击"生成新图号"**：程序会自动生成下一个可用的图号
5. **查看结果**：新图号会显示在结果区域，并自动保存到历史记录

### 编码规则

#### 组件（追加法）
- 格式：父级图号 + 两位数字（01~99）
- 示例：
  - 父级：`03S01201-100101`
  - 已有：`03S01201-10010101`, `03S01201-10010102`
  - 新组件：`03S01201-10010103`

#### 零件（分叉法）
- 格式：父级图号 + `-` + 顺序数字（1, 2, 3...）
- 示例：
  - 父级：`03S01201-100101`
  - 已有：`03S01201-100101-1`, `03S01201-100101-2`
  - 新零件：`03S01201-100101-3`

### 注意事项

- 零件不能作为父级（不能在其下创建子级）
- 组件最多支持99个子组件
- 所有数据保存在 `numbers.json` 文件中
