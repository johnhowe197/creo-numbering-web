树形层级界面版本，与Creo设计树保持一致。

|   │   │   ├─ 05S...| 电机      | 子节点 2     |

## 功能特性

### 1. 树形层级显示
- 类似Creo设计树的层级结构
- **两列显示**：图号 + 名称
- 颜色区分：根节点(蓝)、组件(绿)、零件(黄)
- 支持展开/折叠

### 2. 名称编辑
- **双击名称列**：直接编辑名称
- **支持粘贴**：可粘贴名称或图号文本
- **实时保存**：编辑后自动保存到数据

### 3. 工具栏操作

| 按钮 | 快捷键 | 说明 |
|------|--------|------|
| 新建项目 | Ctrl+N | 创建新的根图号 |
| 打开项目 | Ctrl+O | 加载已保存的项目 |
| 保存项目 | Ctrl+S | 保存当前项目 |
| 添加组件 | Ctrl+Shift+C | 在选中节点下添加子组件 |
| 添加零件 | Ctrl+Shift+P | 在选中节点下添加子零件 |
| 删除 | Delete | 删除选中节点及其子节点 |
| 重命名 | F2 | 重命名选中节点（修改图号） |

### 4. 右键菜单
在树节点上右键可快速访问：
- 添加组件
- 添加零件
- 删除
- 重命名

### 5. 属性面板
点击节点显示详细信息：
- 图号
- 名称
- 类型（根/组件/零件）
- 父级
- 子节点数
- 子组件数
- 子零件数
- 创建时间

### 6. 数据持久化
- 自动保存到JSON文件
- 支持手动保存/加载
- 关闭时提示保存

## 使用流程

### 新建项目
1. 点击"新建项目"或按 Ctrl+N
2. 选择创建方式：
   - **从根图号开始**：输入不带横杠的图号（如 `05S01101`）
   - **从组件开始**：输入带横杠的图号（如 `05S01101-00`）
3. 树形视图显示根节点

### 添加子节点
1. 在树中选中父节点
2. 点击"添加组件"或"添加零件"
3. 程序自动生成下一个可用图号
4. 新节点显示在树中
5. **双击名称列**编辑节点名称

### 编辑名称
1. **双击名称列**进入编辑模式
2. 输入或粘贴名称
3. 按 Enter 或点击其他位置确认

### 重命名图号
1. 选中要重命名的节点
2. 点击"重命名"或按 F2
3. 输入新的图号

### 删除节点
1. 选中要删除的节点
2. 点击"删除"或按 Delete
3. 确认删除（会删除所有子节点）

### 拖拽移动
1. 拖拽节点到新的父节点
2. 松开鼠标完成移动

## 图号格式说明

### 两种创建方式

| 方式 | 输入格式 | 示例 | 第一个子组件 |
|------|----------|------|--------------|
| 从根图号开始 | `[前缀]` | `05S01101` | `05S01101-00` |
| 从组件开始 | `[前缀]-[层级码]` | `05S01101-00` | `05S01101-0001` |

### 层级结构示例

```
05S01101 (根图号 - 整机)
└── 05S01101-00 (第一层级 - 机头)
    └── 05S01101-ZBC (组件/总成)
        ├── 05S01101-01 (零件 - 电机)
        ├── 05S01101-02 (零件 - 减速器)
        └── 05S01101-03 (零件 - 联轴器)
```

### 编码规则

#### 组件（追加法）
- 根图号无横杠：`05S01101` → `05S01101-00` → `05S01101-0001`
- 组件有层级码：`05S01101-00` → `05S01101-0001` → `05S01101-000101`

#### 零件（分叉法）
- 格式：父级图号 + `-` + 顺序数字
- 示例：`05S01101-0001` → `05S01101-0001-1` → `05S01101-0001-2`
